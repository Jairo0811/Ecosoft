# Dominicana Icons — EcoSoft

Patch de identidad visual local aplicado después del cierre funcional del proyecto.

## Integración actual

- `mapa-rd.svg` se usa como marcador institucional discreto en el panel lateral.
- La iconografía funcional de Material UI se conserva para navegación, acciones, permisos, regulación, auditoría y demás controles.
- El icono dominicano es complementario y no comunica estado, error, éxito ni una acción interactiva.

## Accesibilidad

El SVG se renderiza como decoración (`alt=""` y `aria-hidden="true"`). El contexto «República Dominicana» permanece disponible como texto legible.

## Alcance

Este patch no modifica API, autenticación, permisos, modelos de datos, lógica de subastas, IA ni reglas de negocio.

## Activos

Los SVG de este patch provienen del paquete `dominicana-icons` suministrado para el proyecto. La procedencia/licencia del paquete debe conservarse o confirmarse antes de redistribuir los activos fuera de los repositorios autorizados.
