# Contribuir a EcoSoft

1. Cree una rama desde `develop` con el prefijo `feature/`, `fix/`, `docs/` o `chore/`.
2. Use Conventional Commits y mantenga cada cambio enfocado.
3. Ejecute `npm run lint`, `npm run typecheck`, `npm test` y `npm run build`.
4. No incluya secretos, datos reales de empresas ni documentos regulatorios confidenciales.
5. Abra un pull request con contexto, evidencia de pruebas y riesgos conocidos.

Los cambios de autorización, auditoría, contratos PPA o adjudicaciones requieren revisión de al
menos otro integrante del equipo. Ninguna regla regulatoria se implementará sin una fuente formal.
